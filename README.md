### ✨ 主要功能

- **⚡ 协议级最高画质直达**：在底层协议阶段拦截与锁定最高画质，0 轮询模拟点击，开播秒开直达原画，彻底杜绝二次切流卡顿与黑屏等待。
- **📺 同屏多路分屏播放**：支持 2~5 路分屏自由组合，长按拖拽任意换位且流媒体播放不断流，每个分屏格子具备独立音量记忆与自适应画质。
- **🏆 驴酱杯赛程官网直达**：赛程排期、队伍阵容、选手档案、选手榜单与直播支持一键在新标签页直接跳转官方原站，纯净轻量，配备 16 支队伍视角一键直达。
- **📊 弹幕与礼物统计查询**：支持页内穿透查询弹幕发言历史，提供直观的礼物价值柱状图，支持快捷筛选驴酱全员数据或单个主播礼物走势。
