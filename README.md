### ✨ 主要功能

- **⚡ 协议级最高画质直达**：在底层协议阶段拦截与锁定最高画质，0 轮询模拟点击，开播秒开直达原画，彻底杜绝二次切流卡顿与黑屏等待。
- **📺 同屏多路分屏播放**：支持 2~5 路分屏自由组合，长按拖拽任意换位且流媒体播放不断流，每个分屏格子具备独立音量记忆与自适应画质。
- **🏆 驴酱杯赛事专题大屏**：一键呼出「驴酱杯 · S3」专属赛事大屏，赛程排期、队伍阵容、选手档案与选手榜单页内秒开浏览，配备 16 支队伍视角一键直达。
- **📊 弹幕与礼物统计查询**：支持页内穿透查询弹幕发言历史，提供直观的礼物价值柱状图，支持快捷筛选驴酱全员数据或单个主播礼物走势。
- **🎨 全系 MIUIX 工业美学**：告别原生粗糙控件，全面换装现代分段胶囊、跑道弹簧开关与毛玻璃 Dock 栏，视觉风格一致清爽。
- **🛡️ 纯净防护与日常自动化**：标准阻断 WebRTC P2P 上行带宽偷跑，CSS 声明式拦截弹窗与遮罩广告；内置客户端打卡、粉丝家园与积分一键签到。
